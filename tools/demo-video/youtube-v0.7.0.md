Lodestone: A Fast, Free Minecraft Launcher for Every Modpack (v0.7.0 Demo)

## Description

Lodestone is a free, open-source Minecraft launcher, built in Rust, for Windows, macOS and Linux. Search Modrinth, CurseForge, ATLauncher, Technic and FTB in one place, spin up modded instances in seconds, and manage your mods, worlds, servers and skins without leaving the app.

⬇️ Download: https://lodestonelauncher.com
💻 Source code: https://github.com/Drew-Chase/lodestone-minecraft-launcher

What you'll see:
• One library for every instance: Fabric, Forge, NeoForge, Quilt or vanilla
• Discover: search Modrinth, CurseForge, ATLauncher, Technic and FTB together
• Full project pages with descriptions, galleries, changelogs and every version
• New instances in seconds, with the right Java picked for you
• Per-instance mods, files, worlds and settings
• Every world from every instance, with backups and filters
• Live server status: pings, player counts and LAN games
• A 3D skin preview
• Import from other launchers, export modpacks, portable builds, and mod snapshots you can roll back
